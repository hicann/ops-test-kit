# 测试结果

> 执行测试时会在终端打印每个用例的精度比对结果和整体通过率等信息。如果指定了 `-o` 参数，还会输出结果CSV文件。

## 输出CSV结果

通过 `-o` 参数指定输出结果路径：

```shell
python3 -m ttk kernel -i cases.csv -o results.csv
```

输出CSV中包含用例基本信息、编译结果、执行耗时、精度状态等列。

## 查看设备信息

```shell
python3 -m ttk info
```

输出本机所有Ascend NPU设备的硬件信息，包括芯片型号、温度、利用率等。

## 预览用例

```shell
python3 -m ttk list -i cases.csv
```

解析CSV并打印所有测试用例名称，支持按算子名过滤。

# 精度对比方法说明

通过 `--compare` 参数选择精度对比方法：

| 方法 | 参数值 | 说明 | 默认容差 |
|------|--------|------|---------|
| 数值近似 | `close`（默认） | 使用 `np.isclose()`/`torch.isclose()` 进行比对 | fp16/bf16: rtol=0.001; fp32: rtol=0.0001 |
| 余弦相似度 | `cosine` | 基于向量余弦相似度比对 | rtol=0.01 |
| 二进制精确 | `binary` | 逐bit精确比对 | 无容差 |
| 重量化 | `requant` | 适用于float8类型（e5m2/e4m3fn/hifloat8） | 自动适配 |

## 数值近似对比（close）

默认的精度对比方法，分别使用相对误差（rtol）和绝对误差（atol）进行判断：

- 大值域：使用相对误差（rtol），默认 fp16/bf16 为 0.001，fp32 为 0.0001
- 小值域：使用绝对误差（atol），默认 1e-8

CSV中可通过 `precision_tolerances` 字段为每个输出单独设置容差，也可通过 `absolute_precision` 字段设置全局绝对精度。

## 余弦相似度对比（cosine）

将输出向量与Golden向量计算余弦相似度，判断是否大于阈值：

- 默认 rtol=0.01

适用于大规模向量的整体趋势比对。

## 二进制精确对比（binary）

逐bit比较NPU输出和Golden是否完全一致，无容差概念。

适用于整型运算（如int8、int32）或需要精确结果的场景。

## 重量化对比（requant）

专门为float8类型（float8_e5m2、float8_e4m3fn、hifloat8）设计的对比方法。

## 自动切换规则

以下数据类型会自动切换对比方法，无需手动指定：

| 数据类型 | 自动切换到 |
|---------|-----------|
| float8_e5m2, float8_e4m3fn, hifloat8 | `requant` |
| float4, int4 | `binary` |

# 精度调试

## Dump数据

通过 `--dump` 参数保存输入、输出和Golden数据，便于手动分析：

```shell
# Dump全部数据（输入+输出+Golden）
python3 -m ttk kernel -i cases.csv --dump full

# 只Dump输入和Golden
python3 -m ttk kernel -i cases.csv --dump in,golden

# 指定Dump格式为npy（方便numpy加载分析）
python3 -m ttk kernel -i cases.csv --dump in,out,golden --dump-format npy

# 指定Dump格式为pt（方便torch加载分析）
python3 -m ttk kernel -i cases.csv --dump full --dump-format pt
```

Dump格式说明：

| 格式 | 说明 |
|------|------|
| `bin`（默认） | 二进制原始数据 |
| `npy` | NumPy数组文件 |
| `pt` | PyTorch张量文件 |
| `print` | 直接打印到终端 |

## 失败时自动Dump

```shell
python3 -m ttk kernel -i cases.csv --dump-on-fail
```

开启后，精度比对失败时会自动保存全部数据（输入+输出+Golden），便于事后分析。

## 单用例调试

定位到具体失败用例时，组合 `-t` 与 `--dump-on-fail`、`--single-log` 等参数即可获得最详细的调试输出：

```shell
# 单用例 + 失败时自动dump + 独立日志
python3 -m ttk kernel -i cases.csv -t add_01 --dump-on-fail --single-log

# 单用例 + Dump 全部数据为 npy
python3 -m ttk kernel -i cases.csv -t add_01 --dump full --dump-format npy
```

## 固定随机种子

```shell
python3 -m ttk kernel -i cases.csv --seed 42
```

设置固定的随机种子，使得输入数据生成和Golden计算过程可复现。

# 输入数据分布

通过 `--input-dist` 参数控制输入数据的生成分布：

| 分布 | 参数值 | 说明 |
|------|--------|------|
| 均匀分布 | `uniform`（默认） | 在CSV中 `input_data_ranges` 指定的范围内均匀采样 |
| 正态分布 | `normal` | 在指定范围内按正态分布采样 |

# Golden模式

通过 `--golden-mode` 参数控制Golden生成行为：

| 模式 | 说明 |
|------|------|
| `Enable`（默认） | 正常生成Golden并比对 |
| `Disable` | 不生成Golden，仅编译和执行（用于性能测试） |
| `Promote` | 提升Golden精度计算 |
